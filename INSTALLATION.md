# Installation

## Prasyarat
- Python 3.10+ (disarankan 3.11)
- PowerShell (Windows)

## Setup
Dari root folder `METAHEURISTIK2`:

```powershell
./scripts/setup_all.ps1
```

Script akan membuat `.venv`, meng-install dependency, dan menyimpan versi environment ke `docs/REPRODUCIBILITY.md`.
