# Quick Start

1. Setup environment:

```powershell
./scripts/setup_all.ps1
```

2. Jalankan eksperimen:

```powershell
./scripts/run_experiment.ps1
```

3. Lihat metrik terbaru:

```powershell
./scripts/show_latest_metrics.ps1
```

4. Jalankan test:

```powershell
./scripts/run_all_tests.ps1
```
